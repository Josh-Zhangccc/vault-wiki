# tmp：临时区

wiki 的 /tmp：草稿与解析中间产物的合法住所——允许可失败、可不完整。框架此前所有领地都是正式的（不可改 / 只增 / 事实源），中间态没有去处，本插件补此缺口。**对派生层隐身**（同 archive 的排除待遇）：不入 index / tags，不作链接源，断链豁免——草稿里 [[还不存在的页]] 是「尚未写下」的正常态，转正时才要求闭合。

## Structure

- `wiki/tmp/**`——路径即领地，下属一切皆 tmp；type 可标可不标（`type: tmp` 落领地外 → error）
- 平铺容忍，子目录自由，无保留名约束

## Invariants

- 无留存承诺（/tmp 契约）：随时可清理；珍贵草稿及时转正（save 进 notes / 并入 project 决策区等），转正即删稿
- 清理不自动：解析产物随手设 `stale_after`，check 报超龄清单，处置（转正 / 删）经确认；无 stale_after 的草稿不提示——删除属人不破
- 隐身三件套：概念页判定排除（index / tags 不见）、link 不作链接源且不受图检查、hot 天然无关（手写制）
- 敏感提醒：解析中间产物可能含聊天原文等个人数据；实例可 gitignore `wiki/tmp/`
