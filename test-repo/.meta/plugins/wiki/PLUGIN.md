# wiki：md 世界（概念）

内外之分的内侧（与 domain 抽象成对）：wiki 是 md 世界之总集——各域的投影与生于此地的原生知识，agent 与人的公共语言层。本插件是概念声明：只阐述 wiki 是什么、页面出身如何判定，不拥有领地、字段、命令或脚本。

## Structure

容器 `wiki/`，区划出身二分（页面出身三层）：

- 域属地（各域声明属地之页）两形：代理页（默认——可对账外源的投影，vault 资产、lark 对象等，属地路径由各域注入行自披露）与**域内原生页**（域声明的域侧档案——真身在此、无外源可对账，形态归域插件；首例 bb-track 认知档案 user.md；lark 人档、email 人档本带此张力，此番扶正非开口）
- 原生领地（其余）：真身在此的写作物——notes 知识、sessions 纪要、tmp/todo 工作区、profile 认知档案；其中会话页是纪要非镜像：对话运行时消逝后页面即真身，写作即出生（与 lark-im 档案的界线在源是否存活可对账，判据见 domain 域判据）
- 派生设施（index / tags / hot / log）：机械投影，环境零边

横向件（tag / trust / link）占字段与语法、不占页面，不属页面出身分层。

## Invariants

- 路径即出身证明：判定一页是什么，先看它在哪（上述三区），再看 frontmatter；属地归哪个域同样从路径惯例读出，声明本体在各域 manifest
- 库内一切文本 UTF-8、知识页 type 必填、保留名豁免
- frontmatter 取最小 YAML 子集（顶层标量 / 块列表 / 一级块映射）：解析器宽松但边界即此，更复杂结构会静默变形
