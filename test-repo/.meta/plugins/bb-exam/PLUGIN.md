# bb-exam：出题自测（testing 消费侧）

bb-track 管「用户的认知状态是什么」，bb-teach 管「教」（teaching 消费侧），本插件管「检验」（testing 消费侧）——用户指定范围 + 可选样例，生成英文试题 + 中文解析帮用户自测。题型与难度中值对齐样例（无样例回落已知作业、再回落用户习惯），知识点绝不越界，解析回链课件位置，选题与难度参照 bb-track 认知档案、按需读 bb-teach 教学纪要。

## Structure

- 自有容器 `exams/`（新一级目录，agent 全权读写）：每测两份——`<course>/<名>-试题.md`（英文题目）+ `<course>/<名>-答案.md`（中文解析）
- 工作流：解析输入 → 读知识点全集 → 读用户认知 → 定题型与难度中值 → 按需读 bb-teach 记录 → 选题 → 出题 → 写解析 → 落盘 → 写后管道

## Invariants

- 题型参照样例（单选/多选/填空/简答/计算/证明…，不枚举）；难度系数 = 认知层级 1-5（记忆/理解/应用/分析/综合），中值 M 对齐样例（fallback：已知作业 → 用户习惯）
- 题目英文、术语严格对齐 courseware `## 专有名词` 英中对照；解析中文
- 不越界（硬约束）：知识点全集 = courseware sm-N，范围 = 用户指定子集；题/解析只引用范围内知识点，绝不出现课程外知识点（除非用户明示）；越界弃题重出
- 解析标注知识点 + sm-N wikilink（位置即出身）
- 参照 bb-track：熟练度决定选题（生疏/未锚点/错题/短期优先优先测）+ 难度分布（生疏偏易打底、掌握偏难挑战，整体中位数 = M）
- 按需读 bb-teach 记录：近期 session 纪要（bb-teach v0.1 无自有落盘，其记录即会话纪要）
- 隐私：自测卷内容属实例数据，不入框架仓库（exams/ 仅空种子入 git）
