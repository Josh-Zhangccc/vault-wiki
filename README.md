# vault-wiki（工程暂名）

**本项目不是任何 vault 的副本，而是一个全新工程：构建真正普世的 vault-wiki 框架。产出物是文档、技能与脚本，任何人（任何 agent）都能以它们为骨架，建立自己的「信息资产库」。**

- 前身：2026-08-26 建立的个人库结构副本（试验沙箱）。2026-08-28 清空全部副本内容，重新定位为本工程。
- 设计基础：2026-08-25 ~ 08-28 系列讨论收敛的定义与原则，沉淀于 `docs/00-principles.md`。

## 核心定义

- **vault** = 把任意格式的信息存储为资产的容器。
- **wiki** = 信息 → md 解析的管道。
- **个性化是动态内容，不属于架构。**

## 产出物

| 目录 | 内容 | 状态 |
|------|------|------|
| `docs/` | 设计文档：定义、原则、决策留档 | 进行中（00 原则、01 骨架已定稿） |
| `skeleton/` | 通用骨架：目录结构 + 实例宪法模板 + 通用准则（conventions） | 结构就位，内容待建 |
| `skills/` | 普世技能（薄壳：路由 + 读文档） | 未开始 |
| `scripts/` | lint、格式解析器等工具 | 未开始 |

## 与个人库的关系

个人库（agent-obsidian）不再是设计起点，而是本框架的**第一个回填实例**：框架成熟后，按「骨架 + 个人配置层 + 内容」重组。回填前，旧库保持原样不动。

## 工作方式

1. 设计先行：每条准则先在 `docs/` 立稿、讨论、定稿，再落地为 skeleton / skills / scripts。
2. 个人化需求一律记为「实例配置项」，不进架构。
3. 结构文件用 ASCII 文件名（跨平台稳妥），文档内容以中文为主。
