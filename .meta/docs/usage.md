# 使用指南：把命令织成日常

> 读者：部署完成后的库主人（quickstart 的下一步）与想了解协作形态的组员。命令细节以 `.agents/skills/` 各 SKILL.md 披露为准——本文讲**工作流串联**：单条命令怎么连成循环。撰写 2026-10-04。

## 循环一：库经营（通用，每天几分钟）

**输入**：文件丢进 `vault/`，对 agent 说「映射」——得到 `wiki/vault/` 代理页（SHA-256 + 元数据），索引 / 标签 / 热缓存自动更新。对话里出现值得留的洞见，说「保存」——沉淀为 `wiki/notes/` 原生笔记（type 分类、tags 归类）；珍贵草稿从 `wiki/tmp/` 及时转正，转正即删稿。

**取回**：说「检索」——agent 先读热缓存与索引再综合回答，答案带 wikilink 引用，可一路点下去（index 逐层下钻本身是指针结构）。

**受托与提醒**：委托 agent 的事落 `wiki/todo.md`（触发条件 + 一句话）；新 session 开始 agent 先读此页，到期主动提醒，完成即销账（历史归 log）。

**健康**：定期说「检查」——机械项 + 语义项全审计；「画像」随时把对你的新认知收敛进 `wiki/profile.md`（断言带证据、偏好会过期）——称呼、风格等个性化决策前 agent 会先读它。

纪律一句话：**wiki 收蒸馏物不收过程**——过程产物归 vault / tmp / 各域工作区，沉淀的结论才进 notes。

## 循环二：课程学习（bb 域，一学期节奏）

**接课（学期初一次）**：bb-cli 拉取（凭据只存本机）→ `bb/<term>/<course>/` 工作区物化（文档类全量、媒体类指针）→ bb-map 投影出 wiki 属地四桶（info 课程信息 / courseware 知识点 / assessments 作业档案 / attachments 附件）→ 域根 inbox.md 速写（公告蒸馏 + 临近截止 + 未交提醒双源）。

**日常（每周）**：

1. 读 inbox——近窗公告与截止一览
2. 「讲解答疑」（bb-teach）：哪里不懂问哪里——agent 先读认知档案，未知讲透、已知略讲甚至反问你；显著答疑沉淀 ai 笔记进 `notes/`
3. 「出题自测」（bb-quiz）：给范围（可给样例）——英文试题 + 中文解析落 `notes/testing/`；作答后判分，经你确认回流认知档案
4. 「认知档案」（bb-track）：读档 / 差距分析——知识点全集减已锚点集即差距，错题自 assessments 复盘

**闭环**：teach 讲解 → ai 笔记（弱证据）→ track 收敛 → quiz 参照出题 → 判分回流（machine 证据）→ 下轮 teach 按新档伸缩。素材（笔记、考卷、判分过程）住 bb 侧，结论（认知读数）住 wiki 侧——学期走完随 term_status 冻结。

## 循环三：协作开发（组员）

改框架的标准流（详见 AGENTS「提交流程」）：自最新 master 拉分支 → 改 manifest / 命令（动手前读 `log.md` 对表现状与下一步）→ `kernel all` 绿 → 小步提交（`模块: 概述`）→ push 开 PR → 管理者审合。

**装一个新域**（把外部源接进来）：拷对应 connector 进 `connectors/` → plugin 命令装域插件 → 首次使用读连接器 skill 披露（如 bb-cli 的凭据与用法）。域的生长路径与判据见机制详解。

**实验**：一律落 test-repo 沙箱或本地——沙箱实验内容不入史，结论走对话报告或 docs。

## 节奏

- calendar 源日更 = 部署侧 cron 无人值守会话（lark-calendar 设计内建）；bb 数据 TTL 默认 1 天，agent 即同步器——stale 即现拉
- 学期初接课、学期末冻结；每周一次检查 + 差距分析；其余随用随触发——命令是自然语言触发，没有仪式
