# 实验范式：ASRL 披露与零污染度量

> 依据（2026-09-12 两轮实证：虚构库冷启动、真实库 25 件迁移）：真实部署中 agent 只按 ASRL 顺序获知信息、零先验；框架一切「默认已知」都是知识层的不通用（准则 2 试金石延伸）。实证规律——猜错点 = 规范缺样例处；行为离散点 = 规则不在执行现场处；隐性腐化 = 形式层反馈缺失处。

## ASRL：环境唯一的披露通道

1. **A** — AGENTS.md（系统注入，含插件注入区）：身份、准则、结构地图
2. **S** — SKILL.md（命令触发时载入）：流程步骤与锚点指针
3. **R** — 锚点与页面（SKILL 指引的二跳读取：registry、词表、PLUGIN.md、hot、index……）
4. **L** — 执行-观察循环（写后管道输出是唯一的即时反馈层）

除此之外的一切信息——训练先验、实验者的提示、口头惯例——在实验中等同不存在。

## 实验规则（防污染）

- 冷启动 subagent：无对话历史；prompt 只含三样——角色定位、工作目录（环境入口）、用户任务原文
- **提示不得复述任何 SKILL / 规范内容**（例：不得写「记得复用词表」「记得走管道」——那是 S 层职责，复述会虚高度量）
- 交互环节（确认 / 询问）以「实验口径」声明代理方式，但不得顺便给出格式答案
- 需要对照时：改动前后各跑同型实验，比指标；不同时运行互相污染

## 度量与判据

| 指标 | 含义 | 采集 |
|---|---|---|
| 猜测率 | 报告中「靠猜」的决策点数 = 披露空洞数 | agent 自述阅读轨迹与摩擦点 |
| 合规率 | 提交格式 / 管道顺序 / 值集符合比例 | git log + verify + 附检 |
| 披露成本 | 每任务阅读轨迹（文件数、有无源码兜底） | agent 自述读序 |
| 改动有效 | 同型实验下指标显著改善且无新增摩擦点 | 前后对照 |

**改动有效的唯一判据是最后一行，不是「看起来更清楚了」。**
