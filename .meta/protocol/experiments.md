# 实验范式：SASU-L 披露与零污染度量

> 依据（2026-09-12 两轮实证：虚构库冷启动、真实库 25 件迁移）：真实部署中 agent 只按 SASU-L 顺序获知信息、零先验；框架一切「默认已知」都是知识层的不通用（准则 2 试金石延伸）。实证规律——猜错点 = 规范缺样例处；行为离散点 = 规则不在执行现场处；隐性腐化 = 形式层反馈缺失处。

## SASU-L：环境唯一的披露通道

1. **S**（system prompt）— harness 基座：身份、工具集、行为通则。框架不可控，视为给定环境；不同 harness 的 S 差异不归框架的账（含 AGENTS.md 是否自动注入本身也是 S 层属性）
2. **A**（AGENTS.md）— 工作区宪法：系统注入，含插件注入区——身份、准则、结构地图
3. **S**（Skills）— 能力面：技能**描述**在会话起点可得；正文按触发载入——实际读取发生在 L 内
4. **U**（user prompt）— 用户原话：任务语义的唯一合法来源；实验中 U 只含真实用户会说的话
5. **L**（loop）— 执行-观察循环：读锚点、读页面、调工具、写后反馈。锚点与页面（registry、词表、PLUGIN.md、hot、index、存量页）是 **L 内访问的资源，不是独立阶段**；**存量页面是规范的一部分**——agent 以既有页面为格式参照（实证：迁移实验多个 session 查先例页对齐格式），故金样质量即披露质量

前四环是静态可得性顺序；一切实际读取都发生在 L。除此之外的信息——训练先验、实验者塞进提示的规范复述、口头惯例——在实验中等同不存在。

## 测试集矩阵（基准面，版本化）

| 库 | 形态 | 规模 | 作者 | 测什么 |
|---|---|---|---|---|
| S 金样 | 单域重互链 | 10-15 页 | **人类手写** | 质量面：金样标尺、链接图、dedup、hub |
| M 剪藏 | 多域散点 | 30-50 页 | agent 虚构 | 离散面：词表蔓延、孤儿噪声、跨域检索 |
| L 混合 | 混域混密度 | 200-500 页 | 生成器（种子固定） | 规模面：披露阶梯、滚动窗口、成本曲线 |

- 分工原则：**质量被测处用人（S），形态被测处用机器（M/L）**；一切派生页由管道重建保自洽（人写内容，机器保自洽）
- 缺陷注入：每库派生 defect 变体（脚本改哈希 / 删日期 / 造二义别名），逐条标注期望检出级别——check 实验由此可打分（查准查全）
- 标注：检索问题集 + 唯一命中页；摄入素材期望形态——无标注的素材测不出「准」
- 金样页可复制入实例 wiki（自食狗粮）
- 测试集即适应度面：自进化（阶段⑥）的选择压来源

## 交叉验证协议

- 两级验证：**S 筛选**（单库，便宜）→ **全矩阵晋级**（三库同跑）方为正式投入的完整证据
- 有效判据：任一库显著改善且**无库回归**（或显式声明定向优化面 + 其余面不回归）
- 成本曲线是一等指标：同一任务在 S/M/L 的阅读轨迹对比，检验渐进披露的承诺（成本不随库大线性涨）
- 矩阵版本化：快照 + 生成种子固定；**矩阵变更 = 基线变更**，实验报告必须记录矩阵版本（防对考卷改教材）

## 实验规则（防污染）

- 冷启动 subagent：无对话历史；prompt 只含两样——环境供给（角色定位 + 工作目录）与 **U 层用户任务原文**
- **U 层纯度**：不得复述任何 S / A 层内容（例：不得写「记得复用词表」「记得走管道」——那是 Skills 层职责，复述会虚高度量）
- 交互环节（确认 / 询问）以「实验口径」声明代理方式，但不得顺便给出格式答案
- 需要对照时：改动前后各跑同型实验，比指标；不同时运行互相污染

## 度量与判据

| 指标 | 含义 | 采集 |
|---|---|---|
| 猜测率 | 报告中「靠猜」的决策点数 = 披露空洞数 | agent 自述阅读轨迹与摩擦点 |
| 合规率 | 提交格式 / 管道顺序 / 值集符合比例 | git log + verify + 附检 |
| 披露成本 | 每任务阅读轨迹（文件数、有无源码兜底） | agent 自述读序 |
| 改动有效 | 同型实验下指标显著改善且无新增摩擦点 | 前后对照 |

**改动有效的唯一判据是最后一行，不是「看起来更清楚了」。**
