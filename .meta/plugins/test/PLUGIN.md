# test：插件自检（规范示例插件）

> 本插件是第一个按插件布局成形的插件，兼任插件规范的活示例：manifest 见 `PLUGIN.yaml`，本文件是逻辑本体，工具在 `scripts/`。
> 职责边界：只校验**插件的形状**（manifest 与文件布局），不校验**插件干了什么**（行为痕迹属于各工位插件自己的 lint，流程冒烟属于装卸时的实测）。

## 职责

对 `.meta/plugins/` 下每个插件目录做**静态结构校验**（合规三级检查中的第一级），输出通过 / 失败清单。任何插件的装卸操作必须先跑通本校验。

## 流程

1. 枚举 `.meta/plugins/*/`，读取各 `PLUGIN.yaml`；
2. 校验 manifest：必填字段齐全（type / id / version / class / scopes / depends / status / updated / entry.doc）；id 与目录名一致；id 全局唯一；class、status 取值合法；
3. 校验入口文件存在：entry.doc 必在；entry.scripts 列出的文件必在；
4. 校验依赖：depends 中的 id 存在且无环；同层依赖与向上依赖报错（分层方向：协议 → 承重 → 工位 → 个性化）；
5. 与注册表核对（待协议定稿后启用）：磁盘有而未登记 = 未安装，视为不存在；登记有而磁盘无 = 幽灵插件；两者均报 error；
6. 输出报告：`error`（阻断装卸）/ `ok`；有 error 时退出码非零。

## 不变量

- 只读校验：本插件不写任何域（scopes 为空）；
- 只报告，不自动修复——修复动作属于人或对应工位插件。

## 依赖

无。承重件不依赖任何插件（分层的底）。

## 合规检查

本插件自身的合规性由它自己校验（自举）：`check.py` 对 `.meta/plugins/` 全体生效，包括 `test` 自身。
