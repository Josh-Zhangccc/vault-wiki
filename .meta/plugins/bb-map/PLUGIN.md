# bb-map：bb 域映射法则

bb 域的映射法则：把 `bb/` 拉取物（连接器 bb-cli 物化的课件 / 提交件）统一映射为 `wiki/bb/` 的代理页——不论源目录如何存储，映射后统一为特定格式（格式待用户裁定，本文件暂为占位骨架）。代理是「bb 资产在 md 世界的代表」；映射与理解解耦，内容打磨不归本插件。

## Structure

- `wiki/bb/**` 由 `bb/**` 统一映射（映射后格式与密度待裁定）

## Invariants

- 路径即出身证明：`wiki/bb/` 下页面必有 `bb/` 对应物（具体字段与规则随格式一并落地）
- 只读纪律：映射不改 `bb/` 源侧，删改自由属于人
- 实例数据不入框架仓库（课程 / 成绩 / 提交数据随 bb 插件红线）
