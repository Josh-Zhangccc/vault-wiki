# bb-map：bb 域映射法则

bb 域的映射法则：把 `bb/` 拉取物（连接器 bb-cli 物化的课件 / 提交件）统一映射为 `wiki/bb/<term>/<course>/` 的代理页——不论源目录如何存储，映射后统一为 `info.md`（课程信息）+ `lec&tut/`（知识点）两种页形。映射与理解解耦：代理是「bb 资产在 md 世界的代表」，登记 + 简要介绍起步，深度摘要为可选增强。

## Structure

- `wiki/bb/<term>/<course>/info.md` —— 课程信息页（教学大纲 / 分组 / 考试时间，蒸馏自 bb/ 大纲与 assessment 文件）
- `wiki/bb/<term>/<course>/lec&tut/<单元名>.md` —— 知识点页：每个内容单元一份（内容单元 = bb/ 中的目录「课程文件+附属文件合一」或扁平单文件）；正文简要介绍 + `raw_path` 指针

## Invariants

- 路径即出身证明：知识点页 `raw_path` 指向 bb/ 内容单元，失配以路径对账
- 映射不改 `bb/` 源侧，删改自由属于人
- 不复制原文全文：简要介绍一行起步，蒸馏不照搬
- 实例数据不入框架仓库（课程 / 成绩 / 提交数据随 bb 插件红线）
