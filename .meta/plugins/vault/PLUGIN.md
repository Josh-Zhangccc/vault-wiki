# vault：真实资产仓库（概念）

产品名的半边之一：vault 是容纳真实资产的仓库——任意格式（md / txt / csv / pdf / 图像 / 音视频……）原样进入，完整性以哈希登记。本插件是概念声明：只阐述 vault 是什么、立什么规矩，不拥有领地、字段、命令或脚本。

## Structure

无自有结构与文件；根目录 `vault/` 是容器本身。

## Invariants

- 命令侧对 vault 只增：agent 写入只产生新文件，不修改既有文件
- 删改自由属于人：删除、修改、移动是人的权利，命令不执行
- 原文不可变是信任的根基：代理与索引皆可再生，唯原文是唯一真相

## Checks

无附检。

## Inject

AGENTS.md 一行：vault 容纳与只增原则。

## Attachments

无。
