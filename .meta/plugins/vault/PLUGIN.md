# vault：真实资产仓库（概念）

产品名的半边之一：VAULT 是容纳真实资产的仓库——任意格式（md / txt / csv / pdf / 图像 / 音视频……）原样进入，完整性以哈希登记（登记机制归 mapping 插件）。本插件是概念声明：只阐述 VAULT 是什么、立什么规矩，不拥有领地、字段、命令或脚本。

## Structure

无自有结构与文件；根目录 `vault/` 是容器本身。

## Invariants

- 命令侧对 VAULT 只增：agent 写入只产生新文件，不修改既有文件
- 删改自由属于人：删除、修改、移动是人的权利，命令不执行（人的操作经 check 对账后由 mapping 同步代理）
- 原文不可变是信任的根基：代理与索引皆可再生，唯原文是唯一真相

## Checks

无附检；VAULT 侧的对账（积压 / 失配 / 悬挂）由 mapping 插件的附检承担。

## Inject

AGENTS.md 一行：VAULT 容纳与只增原则。

## Attachments

无。
