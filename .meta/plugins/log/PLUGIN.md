# log：运行日志

库的操作流水：什么时候对库做了什么。只增不删的历史，与 hot（会淘汰的现在）相对。

## 结构

- 单文件 `wiki/log.md`，条目置顶追加（最新在最上）
- 条目格式：`- YYYY-MM-DD <类型>：一句话概述`（含 wikilink）
- 类型枚举：摄入 / 保存 / 检查 / 装卸 / 其他（实例可扩）

## 不变量

- 只增不删；修改历史条目 = error
- 每条必须标日期（精确到天）

## 配置

```yaml config
log.max_chars: 2000   # 容量上限（字符）；超限压缩须人确认
```

## 检查（注入 check）

- 历史条目被修改（git 可核）→ error
- 无日期条目 → error
- 容量超限 → warning

## 注入

AGENTS.md 一行：log 语义与置顶追加规则。
