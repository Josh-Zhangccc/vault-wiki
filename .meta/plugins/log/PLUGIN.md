# log：运行日志

库的操作流水：什么时候对库做了什么。只增不删的历史，与 hot（会淘汰的现在）相对。

## 结构

- 单文件 `wiki/log.md`，条目置顶追加（最新在最上）
- 条目格式：`- YYYY-MM-DD <类型>：一句话概述`（含 wikilink）
- 类型枚举：摄入 / 保存 / 检索 / 检查 / 装卸 / 其他（实例可扩）

## 不变量

- 条目只增不改写（「只增不删」的对象是条目内容，非文件物理位置）；修改历史条目 = error
- 每条必须标日期（精确到天）
- 归档搬移不改动条目内容一字

## 滚动机制

主文件是滚动窗口，不是无限账本：

- 窗口 ≤100 条（约 14k 字符；条均约 140 字符，依原库实测校准）
- 任何命令写 log 前查容量：超限则把最旧一段整体搬入 `wiki/log-archive-YYYY-MM.md`（当月一档）
- 归档文件落入不可变区；压缩整合仍须人确认（见宪法准则 5）

## 配置

```yaml config
log.max_entries: 100     # 主文件滚动窗口（条）
log.max_chars: 14000     # 窗口字符上限（约）
```

## 检查（注入 check）

- 历史条目被修改（git 可核）→ error
- 无日期条目 → error
- 容量超限 → 机械归档后复查
