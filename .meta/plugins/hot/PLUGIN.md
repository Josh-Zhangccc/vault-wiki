# hot：热缓存

最近变更的摘要页，agent 进入库的最低成本入口（先读 hot，再按需深入）。

## 结构

- 单文件 `wiki/hot.md`，分节组织（最近摄入 / 最近保存 / 最近检索 / 最近检查……）
- 条目：日期 + wikilink + 一句话核心（≤200 字符，硬上限）

## 不变量

- 可整体再生：hot 只是缓存，丢失可从 log 与库中重建
- 滚动窗口：窗外即删；任何命令写 hot 前先淘汰越界条目、截超长条目（机械自动，不询问）

## 配置

```yaml config
hot.max_entries: 25
hot.max_days: 5
hot.max_entry_chars: 200   # 单条硬上限；参数依原库实测校准（原库单条中位 389 字、最大 4959 字，失控实证）
```

## 检查（注入 check）

- 窗口越界（超 25 条 / 超 5 日 / 单条超 200 字）→ 机械淘汰或截短后复查
- 与 log 矛盾（log 有记录而 hot 全无踪迹）→ warning
