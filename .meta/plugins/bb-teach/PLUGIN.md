# bb-teach：提问即解惑（教学消费侧）

bb-track 管「用户的认知状态是什么」（认知档案 user.md 的生产者），本插件是它的 **teaching 消费侧**——用户提问时实时读认知档案，按「用户熟练度 × 概念难度」二维伸缩讲解。区别于资料整理 Demo 的静态受众模型（写死「大一/大二、先修有限」），bb-teach 对同一知识点、对不同人讲不同深度：已知的略讲/反问，未知的讲透，并主动对齐用户的短期目标与历史错题。默认纯对话输出，不落盘。

## Structure

- 无自有页面（零自有字段复用 trust）；纯只读消费 bb-track 的 user.md 与 bb-map 的 courseware/assessments 页
- 工作流三主步：① 定位知识点（query 检索 + courseware sm-N 收窄）→ ② 读用户认知（读数/证据/目标，stale 先核对，差距/错题现算）→ ③ 按二维矩阵讲解（伸缩 + 术语门槛 + 错题/目标注入 + 锚点回链）
- 可选第四步：三层反馈闭环（见下）

## Invariants

- 二维伸缩：熟练度（未锚点/生疏/熟悉/熟练/掌握，状态词开放）× 概念难度（简单/抽象硬核）；已知不灌输、未知讲透，篇幅与深度随两者伸缩
- 术语门槛动态化：允许出现的专业名词 = 用户**已锚点集**（非「本课前面出现」的静态文件序）；超出者当场解释
- 目标层优先：短期优先（带时效）命中者篇幅 +1 档标「近期重点」、过期降级；命中 assessments 复盘错题点易错点 +1 档并点出
- 三层反馈闭环（防单轮噪声污染画像）：**单轮反馈不落盘**（只调当轮讲法）；**显著答疑**可经 save 落 session 纪要（事实非断言）；仅**显著信号**才提议收敛 user.md——判据 = 跨会话稳定（≥2 次会话独立表现理解）/ 主动正确应用（解题·举反例·正确类比）/ machine 验证（成绩刷新）；写中间态（如「熟悉（初步）」）不强行跳满档，档位提升与证据强度匹配
- 单轮「懂了」= 日常、不算显著；单轮「没懂」不判生疏（可能是讲解责任）
- 只读不越界：不写 bb/ 源侧、不改 courseware/assessments 纯代理、不改 notes/（人的领地，只读 origin/form/stage 作信号）
- 写回委托：user.md 收敛与画像 `## 域认知` 维护走 bb-track 写契约（追加证据流 + 收敛读数「新值取代旧值、证据流不动」+ 认知桥），经用户确认后执行
- log 纪律：讲解过程不写 log（呼应 bb-track「行为信号不采集」红线）；仅认知收敛这一事件走 bb-track 写后管道（log profile --domain bb + verify）
- 隐私：讲解内容与认知结论属实例数据，不入框架仓库与 test-repo
